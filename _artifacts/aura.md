[Aura](https://github.com/elrensmin/aura): a voice-controlled Windows desktop assistant that uses speech recognition and OpenAI's GPT models to control web browsers, search computers, manage emails, and perform screen analysis. The system only supports Windows due to platform-specific dependencies (pywin32, pyautogui, Windows file paths).
